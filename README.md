# Luma — лаунчер

Лаунчер сети Minecraft-серверов Luma на **Tauri 2 (Rust) + React**. Интерфейс собран из дизайн-системы Luma: рейл миров, герой мира с кнопкой «Играть», друзья и пати, гардероб с 3D-скином, магазин, новости, настройки, ⌘K / Ctrl K.

## Что уже настоящее

- **Кнопка «Играть».** Скачивает и сверяет по sha512 все 24 мода сборки (`src-tauri/modpack.json`), убирает старые, ставит Fabric 0.19.5 для Minecraft 1.21.1, создаёт профиль «Luma» в официальном Minecraft Launcher (своя папка игры, память из настроек), добавляет сервер в «Сетевую игру» и открывает лаунчер. Дальше игрок нажимает «Играть» под своим аккаунтом Microsoft.
- **Живой статус сервера** `x1.qwertyx.host:28828`: онлайн, пинг, ники игроков — тем же запросом, что и меню «Сетевая игра» в самой игре, раз в 30 секунд.
- **Скриншоты.** F2 в игре — и снимок сам появляется в лаунчере: последний — в карточке на главной, все — в альбоме (камера в левой панели или Ctrl K → «Скриншоты»). Снимок можно скопировать в буфер и вставить в Discord/Telegram, открыть, показать в папке или удалить. Лаунчер читает только папку `screenshots` игры.
- Своё окно: тайтлбар с перетаскиванием и кнопками окна (на macOS — родные «светофоры»).
- Железо компьютера в настройках; память для игры по умолчанию — половина ОЗУ, от 3 до 6 ГБ.
- Настройки и профиль сохраняются в папку приложения (`settings.json`).
- Установщик Windows в стиле Luma, на русском и английском.

## Что пока не настоящее

- Ник в самой Luma — только для лаунчера. Вход в игру делает официальный Minecraft Launcher: собственный вход через Microsoft в Luma требует, чтобы Mojang одобрила приложение (заявка на aka.ms/mce-reviewappid).
- Гардероб показывает скин только внутри лаунчера.
- Новости пишутся вручную в `src/data.js`.

Сервер и его настройки — в [`server/`](server/README.md).

## Сборка

| Что | Где | Команда | Результат в `builds/` |
|---|---|---|---|
| macOS (Apple Silicon + Intel) | Мак | `bash build-mac.sh` | `Luma_0.1.0_universal.dmg` |
| macOS + Windows | Мак | `bash build-mac.sh --windows` | + `Luma_0.1.0_x64-setup.exe` (cargo-xwin, MSVC) |
| Windows x64 | Ubuntu 24.04 | `bash build-windows-linux.sh` | `Luma_0.1.0_x64-setup.exe` (MinGW) |
| Linux | Ubuntu / Debian | `npm ci && npm run tauri build -- --bundles deb,rpm,appimage` | в `src-tauri/target/release/bundle/` |
| Всё сразу | GitHub Actions | вкладка Actions → build → Run workflow, или тег `v*` | артефакты запуска |
| Разработка | любая | `npm ci && npm run tauri dev` | окно с горячей перезагрузкой |

Нужен Rust 1.90+ и Node 18+. Для Linux-сборки: `libwebkit2gtk-4.1-dev build-essential curl wget file libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev`.

Linux-пакеты, собранные на Ubuntu 24.04, требуют glibc той же версии или новее (Ubuntu 24.04+, Debian 13+, Fedora 40+). Для дистрибутивов постарше подходит сборка из GitHub Actions — она идёт на Ubuntu 22.04.

## Ветки обновлений: Юг и Север

У лаунчера две линии, и игрок выбирает свою в «Настройки» → «О лаунчере» → «Ветка обновлений».

| Ветка | Git | Тег выпуска | Релиз на GitHub |
|---|---|---|---|
| Юг | `main` | `v0.1.4` | обычный — он же «latest» |
| Север | `sever` | `sever-v0.1.4` | pre-release |

Выпуск: поднять версию в `package.json`, `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`, закоммитить и запушить тег своей ветки (`git tag sever-v0.1.4 && git push origin sever-v0.1.4`). Actions соберёт и подпишет сборки, зашьёт в них ветку (`LUMA_CHANNEL`) и выложит `latest.json`. Юг лаунчер проверяет по «latest» (как и раньше), свежий релиз Севера находит через GitHub API. При смене ветки он предлагает её последнюю версию, даже если номер меньше. Релизы Севера помечены как pre-release, поэтому «latest» всегда остаётся Югом, и старые лаунчеры без выбора ветки на Север не перескочат.

## Запуск без подписи

Сборки не подписаны сертификатом разработчика.

- **Windows:** SmartScreen покажет «Windows защитила компьютер» → «Подробнее» → «Выполнить в любом случае». Нужен WebView2 — он уже есть в Windows 10 и 11, а если нет, установщик скачает его сам.
- **macOS:** на своём Маке открывается сразу. На другом — правой кнопкой по Luma → «Открыть».

## Структура

- `src/ds/` — компоненты дизайн-системы Luma (те же исходники, что в `components/bundle.js`).
- `src/screens/` — экраны: вход, главная, миры, гардероб, магазин, новости, настройки.
- `src/native.js` — мост к Rust-командам (в браузере работает на заглушках).
- `src-tauri/` — ядро на Rust, конфигурация окна и пакетов, иконки, картинки установщика (`icons/installer/`).
